# Kitchen / Dining Room Recipes

Our kitchen and dining room form one long room. It is too long to be covered by
a single Everything Presence Pro presence sensor, so we have one sensor in the
dining room area and one in the kitchen area.

This results in us treating this room as three spaces:

- [**Dining room**](dining-room.md): contains the dining room table, over which
    we have the **Table Light**.
- [**Kitchen**](kitchen.md): contains the island, with the **Island Light**, the
    **Island Spots**, and the **Window Light**.
- **Kitchen/Dining Room** *(recipe coming soon)*: contains the general lighting
    for the larger space, i.e. the **Cupboard Lights** which run the full length
    of one wall of the kitchen and dining room, and the **Painting Spots** which
    run along the opposite wall in the Dining Room.

The Dining Room adjoins the Lounge where we watch the projector. Light from the
Dining Room and Kitchen impacts viewing of the projector so we turn the lights
off more quickly when the projector is on.
